# マップ

マップは、送り手のスライダーの番号と、アバターのブレンドシェイプの対応表です。受け手が書き出し、送り手が読みます。

## 保存先と書き出すとき

マップは `%LOCALAPPDATA%\FaceUtil\Maps\マップ名.json` に保存します。受け手の Inspector の `マップのフォルダを開く` か、メニューの `Tools > Poyo's Face Util > Open Map Folder` で開けます。

次のときに書き出します。

- Play Mode に入ったとき
- アバターをアップロードしたとき
- Inspector の `マップを書き出す` か `送り手を起動` を押したとき

設定を変えて Play Mode に入るとマップは新しくなりますが、VRChat のアバターはアップロードし直すまで前のままです。設定を変えたら、アップロードし直してください。

## 衣装違いのアバターでマップを使う { #share }

同じマップ名のアバターは、1 つのマップを使います。同じ素体で衣装だけが違うアバターが何体あっても、送り手のマップは 1 つで済みます。

### 素体の Prefab に組み込む

1. 素体の Prefab を Prefab モードで開きます。
2. アバターを右クリックし、`Poyo's Face Util` → `Setup` を選びます。
3. Prefab を保存します。

`マップ名` には素体の名前が入り、その Prefab から作った衣装違いの Prefab Variant にも引き継がれます。

### あとからそろえる

それぞれのアバターの `Face Util Receiver` で、`マップ名` を同じにします。

マップを共有できるのは、登録したブレンドシェイプのメッシュ・名前・順番が同じアバターだけです。違うアバターで書き出すと、ほかのアバターがそのマップから外れ、`共通マップの構成が変わりました` と警告が出ます。外れたアバターは、そのアバターでビルドし直すとまた入ります。既定の値だけが違うのはかまいません。

## アバターを変えたときの切り替え { #switch }

送り手が VRChat から受信していれば、VRChat でアバターを変えたときに、そのアバターのマップに切り替わり、約 1.5 秒後に Face Util を ON にします。

| 状況 | 送り手の動き |
|---|---|
| そのアバターのマップがある | そのマップに切り替えます |
| マップが同じまま | スライダーを既定の値に戻します |
| マップが見つからない | `このアバターのマップが見つかりません` と出し、今のマップのままにします |

切り替えには、アップロードしたアバターの ID を使います。初めてアップロードしたアバターは、アップロードしたあとで一度 Play Mode に入るか、`マップを書き出す` を押してください。ID の入ったマップになります。
