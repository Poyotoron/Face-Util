# 口パクとまばたき

VRChat は、口パク（Viseme）と自動のまばたきのためにブレンドシェイプを動かしています。Face Util の ON・OFF で、次のように変わります。

| 状態 | 表情 | 口パク | まばたき・視線 |
|---|---|---|---|
| OFF | ふだんどおり（ジェスチャーなど） | 動く | 動く |
| ON、口パクはオフ | 送り手の値 | 止まる。口の形も送り手で決める | 止まる |
| ON、口パクはオン | 送り手の値 | 送り手の表情のまま口パクする | 止まる |

受け手の `ON の間、まばたき・視線を止める` をオフにすると、ON の間もまばたきと視線は動きます。

ON の間は、登録したブレンドシェイプを Face Util だけが動かします。ジェスチャーなどで表情を変えても反映されません。

## 口パクを切り替える

ON の間に口パクを動かすかどうかは、次のどちらかで切り替えます。最初はオフです。

- Expression Menu の `Face Util` → `口パク`
- 送り手の `口パク` のトグル

一方で切り替えると、送り手が受信しているときはもう一方も変わります。アバターを読み込み直すと、口パクはオフに戻ります。

## 口パク・まばたきのブレンドシェイプ

`vrc.v_aa` などの口パク用のブレンドシェイプや、まばたき用のブレンドシェイプも登録して動かせます。受け手の一覧では `（口パク）` `（まばたき）` と出ます。

これらのブレンドシェイプは、ビルドのときに複製を作り、Face Util は複製のほうを動かします。元のブレンドシェイプは VRChat が動かすので、OFF の間はふだんどおり口パクとまばたきをします。ON で口パクがオンのときは、Face Util で作った口の形に口パクが重なります。

表情ファイルと AnimationClip には、`vrc.v_aa` などの元の名前で保存します。複製の名前は使いません。
