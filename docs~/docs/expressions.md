# 表情と AnimationClip

送り手で作った表情は、表情ファイルか AnimationClip として保存できます。どちらも送り手の `表情を読み込む…` で読み込めます。

| 形式 | 中身 | 使いどころ |
|---|---|---|
| 表情ファイル（`.json`） | 既定の値から変えたブレンドシェイプだけ | 作業の途中の保存、別のアバターでの読み込み |
| AnimationClip（`.anim`） | 登録したブレンドシェイプすべての値 | アバターの表情として使う |

## 表情ファイル

送り手の `表情を保存…` を押し、保存する場所を選びます。既定の場所は `%LOCALAPPDATA%\FaceUtil\Expressions\`、ファイル名は `マップ名_日時.json` です。

保存するのは、既定の値から変えたブレンドシェイプだけです。別のアバターで読み込んだときに、体型など表情に関係ないブレンドシェイプを変えないためです。

表情ファイルには、メッシュのパスとブレンドシェイプの名前を記録します。読み込むときは、次の順にブレンドシェイプを探します。

1. メッシュのパスと名前の両方が一致するもの
2. 名前だけが一致するもの（アバターに 1 つしかないとき）
3. 見つからなければ既定の値

同じ素体の衣装違いのアバターなら、顔のメッシュの名前が違っても（`Body` と `Face` など）、同じ名前のブレンドシェイプに入ります。読み込むと `表情を読み込みました（N 件を適用、M 件はこのアバターにありません）` のように結果が出ます。

## AnimationClip を読み込む

送り手の `表情を読み込む…` で、Unity の AnimationClip（`.anim`）も開けます。クリップの値がスライダーに入り、Face Util が ON ならアバターに送ります。今ある表情のクリップを VRChat で確かめ、スライダーで直してから保存し直す、という使い方ができます。

- Unity の Asset Serialization が `Force Text`（既定）で保存されたクリップだけを読めます。ほかの形式のクリップでは `テキスト形式で保存された AnimationClip だけを読み込めます` と出ます。
- 時間で変わるクリップは、ブレンドシェイプごとに最初のキーの値を使います。このときは `時間で変化するカーブは最初のキーの値を使いました` と出ます。
- ブレンドシェイプ以外のカーブは読みません。

## AnimationClip として保存する

送り手の `AnimationClip として保存…` を押し、Unity のプロジェクトの `Assets/` の中に保存します。Unity に切り替えると取り込まれます。

- 登録したブレンドシェイプすべての値を書きます。既定の値のままのものも書くので、Write Defaults がオフのアバターでも前の表情が残りません。
- 保存のダイアログは、前に AnimationClip を保存したか読み込んだフォルダから開きます。
- 今あるクリップに上書きしても `.meta` は変わらないので、そのクリップを使っている Animator やメニューはそのまま使えます。AnimationClip ではないファイルを選んだときは、上書きせずに `AnimationClip ではないファイルは上書きできません` と出ます。

### 表情を直して保存し直す

1. 送り手の `表情を読み込む…` で、直したい表情のクリップを開きます。
2. VRChat で見ながら、スライダーで直します。
3. `AnimationClip として保存…` で、同じクリップを選んで上書きします。
4. Unity に切り替えると、クリップが新しくなります。

## Unity で表情ファイルから AnimationClip を作る { #unity }

受け手の Inspector の `表情ファイルから AnimationClip を作る…` でも、表情ファイルから AnimationClip を作れます。

1. 表情ファイルを選びます。
2. 保存する場所を `Assets/` の中から選びます。

別のアバターで保存した表情ファイルでも、このアバターのメッシュのパスでクリップを作ります。今あるクリップを選ぶと、中身だけを書き直します（GUID は変わりません）。
