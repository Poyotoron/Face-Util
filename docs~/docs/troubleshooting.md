# 困ったときは

## スライダーを動かしてもアバターが変わらない

次の順に確かめてください。

| 確かめること | 対処 |
|---|---|
| VRChat で OSC が有効か | Action Menu の Options → OSC → `Enabled` をオンにします |
| 送り手の `Face Util` が ON か | ON にします |
| 開いているマップが今のアバターのものか | 送り手でマップを選び直します |
| 設定を変えたあとにアップロードし直したか | アップロードし直します |
| アバターを上書きでアップロードした直後か | 下の「上書きでアップロードしたら OSC が効かない」を見てください |
| 送信先が正しいか | `⚙` で `127.0.0.1` と `9000` になっているかを確かめます |

## 上書きでアップロードしたら OSC が効かない

VRChat は、アバターごとの OSC の設定ファイルを保存しています。パラメータを追加したアバターを上書きでアップロードすると、古い設定のまま OSC を受け付けないことがあります。Action Menu の Options → OSC → `Reset Config` を実行してください。

## 一部のブレンドシェイプだけ動かない

| 原因 | 対処 |
|---|---|
| 受け手の一覧でオフになっている | オンにして、アップロードし直します |
| 区切りとして扱われている | `区切りを編集` で区切りから外し、アップロードし直します |
| `（固定）` と出ている | AAO Avatar Optimizer で固定されるので動かせません（[ほかのツールとの併用](other-tools.md)） |

## ON にすると体型や衣装の形が変わる

ON の間は、登録したブレンドシェイプがすべて送り手の値になります。体型の調整や衣装用の縮小などのブレンドシェイプは、受け手の一覧でオフにしてください。ビルドのときに値を変えるツールを使っているときは、[ほかのツールとの併用](other-tools.md)も見てください。

## ほかのプレイヤーから見た表情が違う

送り手はブレンドシェイプを 1 本ずつ順に送るので、たくさん動かした直後はすべてが届くまで時間がかかります。しばらく待ってもそろわないときは、`⚙` で保持時間を長くしてください。

## アバターを変えてもマップが切り替わらない

| 確かめること | 対処 |
|---|---|
| 受信の状態が `VRChat から受信中` か | `受信できません…` と出ているときは、下の「受信できません」を見てください |
| そのアバターを初めてアップロードしたか | アップロードしたあとで一度 Play Mode に入るか、`マップを書き出す` を押します |
| `このアバターのマップが見つかりません` と出る | そのアバターの受け手でマップを書き出します |

## 「受信できません」と出る

送り手は VRChat からの OSC を `127.0.0.1:9001` で受け取ります。ほかの OSC のアプリが 9001 番を使っていると受け取れません。送信はできます。

- ほかの OSC のアプリを閉じてから、`⚙` で `保存` を押すと、受信をやり直します。
- 受信ポートを変えるときは、VRChat の OSC の出力先も同じポートに変えてください。

## AnimationClip を読み込めない

| 表示 | 原因 |
|---|---|
| `テキスト形式で保存された AnimationClip だけを読み込めます` | Asset Serialization が `Force Text` 以外で保存されたクリップです |
| `対応していないファイルです` | AnimationClip ではありません |
| `… 件はこのアバターにありません` | クリップのブレンドシェイプが、今のアバターにありません |

## 保存した AnimationClip が Unity に出ない

Unity のプロジェクトの `Assets/` の中に保存したかを確かめてください。保存したあと、Unity に切り替えると取り込まれます。

## 「共通マップの構成が変わりました」と出る

同じマップ名で、登録したブレンドシェイプが違うアバターを書き出しました。衣装違いでマップを共有するなら、それぞれのアバターで登録をそろえてください。別のマップにするなら、`マップ名` を変えてください（[マップ](maps.md#share)）。
